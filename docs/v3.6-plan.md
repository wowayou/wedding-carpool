# v3.6 计划：页眉和页脚改版（参考 Funner 的页脚）

分工：主代理出方案和验收，Sonnet 子代理执行。**发布前把截图给站长看，站长同意了才发布**，因为这是视觉上的改动。

## 已定的决定（2026-10-08）

- **参考**：<https://www.footer.design/sites/funner>，即 Funner 网站的页脚。截图在 scratchpad 的 `ref-desktop.png` 和 `ref-mobile.png`。它的特点：
  - 左边是品牌和一个带下划线、末尾有箭头的输入行，右边是四列链接，栏目标题加粗；
  - 底部是一整幅单线描出的大字标「funner」：线条圆头圆角，字母里嵌着彩色圆盘，线的末端是圆点；
  - 手机上链接排成两列两行，大字标换成更紧凑的排法。
- **学什么、不学什么**：
  - **学**：版式（左边品牌加引导，右边四列链接）、留白、加粗的栏目标题，以及底部「一根线串起几个彩色点」的大字标。拼车本来就是一条路线串起车主、乘客、车站、目的地，这个画法正好合用。
  - **不学**：纯白底、它的配色和标志。按 `docs/design-system.md` 的原则，保留暖色纸底和赭红强调色，用系统字体，不加载网络字体；深色模式要一起支持。
- **大字标的内容**：用单线画小写的 **carpool**（就是域名）。
  - 两个 `o` 画成实心彩色圆盘，中间有一个小圆点，像车轮，也像站点；
  - 线条末端加小圆点；
  - 颜色只用现有的语义变量：`--drive`、`--ride`、`--station`、`--dest`、`--accent`，线条用 `--ink`。这样深色模式会自动跟着变。
- **页眉**：
  - 和页脚用同一套语言：品牌名加粗，导航链接的样式和页脚链接一样，当前页用强调色下划线标出；
  - 右侧的操作改成「试玩」（次要按钮）和「新建行程」（主按钮）。GitHub 只留在页脚。
  - 手机菜单（800px 以下）的交互不变，只改样式。
- **范围**：
  - 用页眉页脚片段的所有站点页面：首页、示例、指南、场景页、隐私、关于、更新记录、样式指南、404。
  - 编辑页、试玩页和管理页是工具界面，**保留紧凑的工具栏，不加大页脚**，品牌标志和字体与站点一致即可。
  - 方案页（`share.py`）有自己的页脚，这次不动。

## A. 页脚 `web/partials/footer.html` 和 `design.css`

- **上半部分**，桌面宽度（960px 以上）分左右两块：
  - **左边**：
    - 品牌标志（`/favicon.svg`）加「拼车出行规划」，再加一句话介绍；
    - 一行仿照 Funner 输入行的**引导链接**「先试玩一下，不用邀请码」，带下划线，末尾是箭头图标，指向 `/try`。
  - **右边**：四列链接，栏目标题加粗：
    - **产品**：新建行程、试玩、示例方案页、更新记录；
    - **指南**：使用指南、怎么选高铁站、方案是怎么算出来的、常见问题；
    - **场景**：婚礼、同学或家庭聚会、团建和公司活动；
    - **关于**：关于这个工具、费用与隐私、GitHub 源码、许可证、反馈问题、作者主页。
- **底部小字**：保留现有的内容，包括高德的说明、「非商业的个人项目」、版本号和 LINUX DO 致谢。
- **最下面是大字标**：
  - 内嵌 SVG，`aria-hidden="true"`、`focusable="false"`，不占读屏；
  - 线宽和圆头圆角参考 Funner；
  - 桌面上占满容器宽度。手机（640px 以下）用另一份更紧凑的排法，比如「car」和「pool」分两行，让字母保持够大；两份 SVG 用 CSS 切换显示；
  - 颜色全部用 CSS 变量，不写死色值；
  - 静态的，不加动画。
- **背景**：页脚和页面同底色（`--bg`），靠留白和一条细分隔线分开，不再用整块 `--surface-2` 的底。
- **打印**：打印时整个页脚连大字标一起隐藏，保持现状。

## B. 页眉 `web/partials/header.html` 和 `design.css`

- 结构不变，还是品牌、导航、操作，手机菜单的脚本也不变。
- 操作改成两个按钮：「试玩」（`c-btn` 默认样式）和「新建行程」（`c-btn--primary`）。手机菜单展开后也要能看到这两个按钮。
- 视觉上和页脚呼应：品牌名加粗；导航文字用 `--ink-2`，悬停变 `--ink`，当前页用 `--accent` 下划线标出；底部一条细线。
- 「场景」下拉、键盘焦点、`aria-current` 的行为保持不变。

## 验收

- `npm test` 全过；构建时的站内链接检查和对比度检查（`check-contrast`）都要通过。
- 新增静态检查：
  - 页脚的 SVG 带 `aria-hidden="true"`；
  - SVG 里没有写死的颜色，`fill` 和 `stroke` 只用 `currentColor` 或 `var(--…)`，或者交给 CSS 类；
  - 页眉的操作区有 `/try` 和 `/#create`。
- **截图**：在本地 `wrangler dev` 下用 Playwright 截图，存到 scratchpad：
  - 首页、使用指南、隐私页、404，各截 1280、800、390 三种宽度，浅色和深色（`colorScheme`）都要；
  - 390 宽时，手机菜单展开后再截一张；
  - 检查没有横向滚动、没有脚本错误；
  - 键盘按 Tab 能依次走过页眉和页脚的链接，焦点框看得见。
