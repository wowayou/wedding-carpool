# v3.5 计划：试玩模式（不用邀请码、不调用高德）

分工：主代理出方案和验收，Sonnet 子代理执行。

## 已定的决定（2026-10-08）

- **背景**：站长想让没有邀请码、也申请不了高德 Key 的人能试用。要给公众放出真实额度，得等高德商务的答复，因为工单里写的是「邀请制，只给亲友用」，问题已加进 `carpool-ops/amap-business-call-prep-2026-10-08.md` 的第 10 问。所以先做**试玩模式**。
- **试玩不调用高德 Web 服务**：
  - 行车时间按直线距离估算，是示意值；
  - 路线画成直线；
  - 地图底图仍然用高德瓦片，和示例页一样，加载瓦片不算 Web 服务调用。
- **不录制真实的高德数据**：
  - 高德条款不允许存储、缓存它的数据，这正是商务对接要问的第 4 问。录下来放进公开仓库、长期提供出去，风险比示例页更大。
  - 等商务答复允许了，再考虑换成真实数据。数据格式要留好余地，到时只换数据源，不改界面。
- **试玩时能改和不能改的**：

  | 能改 | 不能 |
  |---|---|
  | 谁开车、空座、最多绕路、同行人数、到家附近接、车次和分钟数 | 搜索地点、改地址 |
  | 删除成员、删除候选站 | 加成员、加车站、推荐车站 |
  | 返程的设置、各项选项 | 保存、同步、历史、发布方案页 |

  另外有「恢复示例」按钮，一键回到初始配置。
- **入口**：`/try`。首页新建表单旁边、使用指南里各放一个入口。
- **统计**：`/try` 计入页面访问。自部署的人没把 `/try` 加进 `run_worker_first` 也能用，因为它就是静态的 `try.html`，只是不计数，所以**不算不兼容**。

## A. 试玩数据 `web/try-trip.json`

- 虚构行程，和示例页同一套人物：
  - 目的地：宏村示例酒店；
  - 老王：杭州，开车，空 3 座；
  - 老张：南京，开车，空 2 座，最多绕 20 分钟；
  - 小李：上海，不开车，同行 2 人；
  - 小陈：武汉，不开车。
- 候选站 4–6 个，比如黄山北、黟县东、绩溪北、歙县北、祁门。
- 两位乘客都填了到其中几个站的车次，车次和时刻是虚构的。
- 开启返程：填散场时间，乘客填回程车次。
- `options.estimate_rail = false`，所以试玩时不需要公交估算。车次清空的话，按默认的每站 60 分钟算。
- 坐标用公开的近似值，文件里写明「坐标和车次是示意」。
- 出发日期在加载时设成「下一个周六」，返程是第二天，免得日期过期以后校验报错，12306 链接也能用。

## B. 计算：`browser.py` 里加 `TryAmap`

- `drive_minutes`：直线公里数 × 1.3 ÷ 75 km/h，换成分钟后再加 10 分钟（进出城），同一个点算 0。
- `drive_path`：依次连接各点的直线。
- `geocode`、`search`、`find_station`、`stations_near`、`stations_around`、`transit`：一律抛出 `AmapError`，提示「试玩模式不能查新地点和公交；想用真实地点，请新建行程」。
- `handle('init', {"try": true})` 时用 `TryAmap`。**试玩时任何路径都不能发网络请求**：`TryAmap` 不继承 `BrowserAmap` 的请求代码。
- **报告不能说数据来自高德**：
  - 报告顶部加一条提示，写法和现有的 `warnings` 一样：「试玩：行车时间按直线距离估算，路线画成直线，不是真实路况。」
  - 「说明」里「时间来自高德驾车测距……」那条，试玩时换成试玩的说法。
  - 用什么办法实现由执行代理决定，但不能改变正式行程的报告，要有测试。

## C. 编辑页：第三种模式 `try`

- **怎么判定**：`/api/env` 返回 `online`，并且路径是 `/try` 或 `/try.html`，就是 `mode = 'try'`。本地版不受影响。
- **加载**：读 `/try-trip.json`。不调用 `session`、`config`，不连 WebSocket。
- **保存**：不保存，也不提示「有未保存的修改」。刷新页面就回到示例。
- **禁用或隐藏**：
  - 搜索按钮，地址输入框设为只读；
  - 加成员、加车站；
  - 推荐车站：换成一句说明；
  - 发布方案页：换成「看示例方案页」链接，指向 `/demo`；
  - 「更多」里的改名、重置链接、编辑口令、历史、删除、导入（导出可以保留）；
  - 在线名单、额度提示、到期提示。
- **顶部横幅**（`c-alert`）：
  - 文案：「试玩模式：虚构的行程，行车时间按直线距离估算，不保存。想规划你们自己的出行，请新建行程（需要邀请码或高德 Key）。」
  - 按钮：「恢复示例」「新建行程」（指向 `/#create`）。
- 地图、手机分页签、步骤条、12306 链接照常工作。
- **不能出现任何 `/api/t/` 请求，也不能有高德 Web 服务请求。**
- **不能影响在线模式和本地版**：改动集中在 `mode === 'try'` 的分支里，不重构现有流程。

## D. 构建和 Worker

- **`web/build.mjs`**：
  - 在 `vendor()` 之后把 `dist/edit.html` 复制成 `dist/try.html`，保证 CDN 地址已经换成 `/vendor/`；
  - 在 CSP 的页面表里加 `try.html`，策略和 `edit.html` 一样；
  - 把 `web/try-trip.json` 拷到 `dist/`。
- **`web/worker.js`**：`PAGE_PATH_RE` 加上 `try`，`/try` 计数后交给静态文件。安全头和编辑页一样，带 `frame-ancestors 'none'`。
- **`wrangler.jsonc`**：`run_worker_first` 加 `"/try"`。
- **`web/_headers`**：确认 `try.html` 有和编辑页一样的安全头。
- `try.html` 和编辑页一样带 `noindex`。

## E. 入口和文档

- **首页**：新建表单附近加一行「没有邀请码？先试玩一下」，链到 `/try`。
- **使用指南**：加一句，说明可以先到 `/try` 试玩。
- **隐私页**：「页面访问次数」的列表加上「试玩」；写明试玩不保存，也不调用高德。
- **README**：「在线版」一节加上试玩。
- **CHANGELOG**：加 `## 3.5.0（未发布）`，说明不算不兼容（`run_worker_first` 加 `/try` 只是为了计数）。

## 验收

- **`npm test` 全过**，新增的测试至少覆盖：
  - `TryAmap` 不发任何请求；
  - 遍历「谁开车」的所有组合、改空座、删站、开关返程，都能算出方案或给出合理的提示，不会报错崩溃；
  - 试玩报告里不说「来自高德」，正式行程的报告不变；
  - 地点搜索时的提示文字；
  - 构建产物里有 `try.html`，CSP 和 `edit.html` 一致，`try-trip.json` 也在；
  - Worker 对 `/try` 计数，并返回页面；
  - 编辑页的静态检查：试玩模式隐藏了发布按钮，禁用了搜索。
- **浏览器验收**：用 Playwright 在 Chromium 和 WebKit 的 iPhone 模拟上：
  - 打开 `/try`，点「计算方案」，出方案和地图；
  - 把老张改成不开车再算；改空座；删一个站；开关返程；
  - 「恢复示例」能用；
  - 首页的入口能到；
  - 全程没有 `/api/t/`、`amap` 相关请求，没有脚本错误，390px 宽时没有横向滚动。
- **在线编辑页没退化**：管理页新建一个行程，确认编辑页能正常加载、编辑和同步，不点搜索和计算。
- 全程**不调用高德 Web 服务**。
