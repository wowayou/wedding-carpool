# v3.3 计划：费用与数据安全交叉验证、编辑页重绘修复、跨浏览器、自部署与 SEO

分工：主代理出方案和验收，Sonnet 子代理执行。

## 已定的决定（2026-10-08）

- **费用和数据安全按「交叉验证」做**：
  - 两个子代理用不同方法，独立审计同一个范围：
    - 一个读代码做静态审计；
    - 一个在本地实际攻击做动态审计，用无效的高德 Key，不产生任何费用。
  - 主代理逐条核对两份结果：
    - 两边都发现的，确认；
    - 只有一边发现的，主代理复现后再定。
  - 确认的问题由修复切片处理，每个修复都要有防回归测试。
  - 账户层面的事实，比如套餐、有没有买流量包，代码里查不到，由站长在控制台确认，结果记在本文。
- **代码层面的费用护栏不依赖账户状态**：即使账户里有付费套餐或流量包，代码里的每日上限、每月预算、应急开关也要保证调用量有上限。
- **自部署和 SEO**：
  - 构建时可以设 `SITE_ORIGIN`，默认是官方域名；
  - 用别的域名构建、又没有显式设 `SITE_INDEXABLE=1` 时，内容页加 `noindex`，robots 禁止抓取，不生成 sitemap；
  - 这样自部署的副本默认不和官方站抢搜索结果。

## A. 编辑页重绘吞点击（优先）

- **原因**：在日期、成员名等字段失焦时触发 `change`，`rerenderKeepingFocus()` 会重建整张表单，正在按下的那次点击落到了被替换掉的元素上。
- **修法**：失焦时不再重建整张表单，只更新受它影响的部分：12306 链接的地址、默认值提示、占位文字、步骤条状态、校验提示。只有结构变化才整体重绘，比如加人、删人、勾选开车、开关返程。
- **验收**：
  - 改出发日期，紧接着点另一个输入框并打字，字落在第二个输入框里；
  - 改返程日期后，紧接着点「计算方案」，计算开始；
  - 12306 链接和提示跟着变；
  - 用 Playwright 在 Chromium、Firefox、WebKit 上都要验证。

## B. 遮罩的焦点管理

- 取名、编辑口令、额度、打不开、已删除这几个遮罩：
  - 打开时把焦点放到第一个输入框或主按钮；
  - 遮罩后面的内容设 `inert`，Tab 键出不去；
  - 关闭后焦点回到原处；
  - 能关闭的支持 Esc 键。
- 弹窗（`<dialog>`）已有原生的焦点管理，确认一下即可。

## C. 跨浏览器

- 在 Firefox、WebKit（Safari 的内核）、WebKit 手机模拟（iPhone）上跑：
  - 主代理的全站验收；
  - 编辑页的主要流程：计算环境初始化、地图、页内弹窗、手机分页签、发布方案页。
- 修复发现的问题。真机测不了的部分写进已知限制。

## D. 费用与数据安全审计（交叉验证）

**审计范围**（两个审计子代理相同）
- **费用**：
  - 所有对外调用：高德、CDN 下载等；
  - 所有限额：
    - 行程每日上限、全站每日上限、每月预算；
    - 八成预留、邀请码、单 IP 新建上限；
    - 应急开关；
  - 并发下这些限额会不会被突破；
  - 有没有绕过限额调用站长 Key 的路径；
  - Cloudflare 各项免费额度（Workers、DO、KV）在最坏情况下会怎样；
  - 统计写入量。
- **数据安全**：
  - 每个接口和 Durable Object 路径的鉴权矩阵：编辑密钥、编辑口令、管理会话、方案页口令；
  - 返回给客户端的数据里有没有不该有的东西：自带 Key、别的行程、行程内容出现在管理页；
  - 删除和到期是否真的删干净：配置、历史、方案页 KV、配额标记、统计里的行程名单；
  - XSS、CSRF、点击劫持、方案页沙箱、暴力猜测；
  - 日志里有没有敏感信息；
  - 隐私页的**每一条说法**都对照代码核实。

**输出格式**（每条发现）
- 编号、严重程度：
  - P0：可能产生费用、泄露数据或误删数据；
  - P1：限额或鉴权有缺口，但利用条件苛刻；
  - P2：说法和实现不一致，或可以加固。
- 类别、证据（文件:行，或复现步骤和输出）、影响、建议修法、把握程度。
- 也要列出**检查过且没问题的项**，便于核对覆盖面。

## E. 修复与防回归（审计之后）

## 需要站长确认的（账户层面）

1. **Cloudflare 套餐**：控制台 → Workers & Pages → Plans，确认是 Workers Free。只有 Free 套餐超额时才只报错、不扣费。
2. **Cloudflare 付款方式**：账户里有没有绑定付款方式、有没有其他付费服务，比如 R2、付费套餐。
3. **高德账户**：控制台里有没有买过流量包，有没有余额。有的话超出免费额度后会消耗它；代码里的每月预算仍然会限制用量。
4. **AI 爬虫**：要不要只对 carpool 子域名放行 GPTBot、ClaudeBot。
