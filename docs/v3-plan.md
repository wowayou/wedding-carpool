# v3 计划：开源授权、安全与隐私、邀请码、插件化内核（返程、同行人数）

已定的决定（2026-10-07）：

- 仓库保持公开，许可证为 **AGPL-3.0-or-later**，另附 `LICENSING.md`。
- 用站长 Key 新建行程改为**邀请码**；站长口令只用于管理页。
- 方案页**默认模糊车主出发地**，可选**访问口令**；编辑链接和方案页链接都可以**重置**。
- **数据保留期**：出行日期过后 60 天，或连续 180 天没人编辑，自动删除；删除前 7 天在编辑页提示。
- 内核**插件化**：去程是基础，返程是第一个插件；**同行人数**进内核。嵌入组件和 TypeScript 重写放到 v4。

## 1. 开源与透明

- `LICENSE`（AGPL-3.0）、`LICENSING.md`（保留另行授权的权利；贡献者授予再授权权利；第三方资源与数据来源说明）；源码文件加 SPDX 标识。
- 站内「费用与隐私」页 `/privacy`，写清以下内容：
  - 存了什么、没存什么、存在哪、谁能看；
  - 交给了哪些第三方；
  - 保留多久、怎么删除；
  - 可能产生费用的地方，以及超出额度时会怎样。
- 验收：首页、编辑页、方案页都能找到这一页；内容与实际实现一致。

## 2. 安全与隐私

- 修复：编辑页报告用 Markdown 渲染时，会原样输出成员名字里的 HTML，构成存储型 XSS。改为转义所有 HTML。
- WebSocket 握手校验来源（Origin），防止其他网站借用户的 Cookie 建立连接。
- 方案页模糊车主出发地：不标精确位置，路线从出发地约 1.5 公里外开始画，标签只写「某某出发」。
- 方案页访问口令（可选）、停止分享、换一个方案页链接（方案页改用单独的 id）。
- 重置编辑链接：生成新密钥，旧链接和旧 Cookie 立即失效。
- 数据保留期：用行程实例上的定时任务（alarm）到期删除；编辑页在删除前 7 天开始提示；方案页存储设过期时间。
- 验收：Worker 单元测试覆盖每一项；浏览器实测 XSS 不再执行、旧链接失效、口令页可用。

## 3. 邀请码与管理页

- 管理页 `/admin`：用站长口令登录，可以对邀请码做这些操作：
  - 生成：设备注、最多新建几个行程、有效期、每个行程每天的高德上限；
  - 查看：已经建了几个行程、用了多少额度；
  - 停用。
- 用邀请码新建的行程会记下所用的邀请码。邀请码停用后，这些行程不能再用公共额度计算，要改用自己的 Key；已有数据不受影响。
- 邀请链接 `/?invite=xxxx`，打开后自动填好邀请码。
- 全站公共额度用量超过 80% 后，当天新建的行程不再分配公共额度，保证已经在算的行程能算完。
- 验收：Worker 单元测试覆盖邀请码的生成、次数、过期、停用、额度归属；管理页实测。

## 4. 插件化内核：去程、返程、同行人数

- 内核以「一段行程（leg）」为单位求解：
  - **去程**：车主从家出发，接人后到目的地；
  - **返程**：车主从目的地出发，送人到车站或顺路的家，再回自己家。
  - 绕路、座位、时间约束都按方向处理：去程是「到站后多久能上车」，返程是「发车前多久要到站」（高铁默认提前 40 分钟）。
- 插件接口：配置字段、求解、报告和方案页段落。返程作为第一个插件。
- 同行人数：一组人要么一起上同一辆车，要么建议整组打车；座位按人数算。
- 编辑器：
  - 「返程」开关，开启后填散场时间；
  - 不开车的人填返程车次，各站同样提供 12306 查询链接；
  - 车主可以设返程是否接送、返程最多绕路。
- 方案页分「去程」「返程」两部分。
- 验收：Python 单元测试覆盖返程的绕路和时间约束、同行人数不拆组、去程结果不变；浏览器实测开启返程后的完整流程。
