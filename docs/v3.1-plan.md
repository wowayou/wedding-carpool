# v3.1 计划：安全加固、管理后台应急、额度透明、产品质感

定位（2026-10-07 明确）：这个工具最重要的作用是**先定个大方向、心里有个底**，具体细节同行的人之间再沟通。不追求精确排程；界面和文案都按「初步方案」来写。

已经先做完的紧急修复：方案页放进 CSP 沙箱（提交 d4a985e）。方案页的 HTML 由编辑者的浏览器上传，之前和本站同源，可以读到打开者浏览器里的编辑链接。

## A. 账号安全与管理后台（Worker、管理页、编辑页的鉴权部分）

1. **编辑口令（可选，默认关）**
   - 设了以后，新设备打开编辑链接要先输入口令；已经在线的其他人会被断开、要求输入口令。
   - 每个行程每小时最多试 10 次。
   - 在「更多」里设置或清除；清除后只凭编辑链接就能打开。
2. **站长口令只用于管理页**：首页不再接受站长口令当邀请码。管理页加「用公共额度新建行程」，直接给出编辑链接。
3. **管理会话**
   - 登录后发随机会话令牌（不再是口令的哈希），24 小时过期。
   - 「退出所有管理会话」一键作废。
   - 登录按 IP 限次，全站另有总上限；口令比较用常数时间。
4. **应急开关**：管理页置顶，操作要二次确认，操作记录保留最近 50 条。
   - 暂停公共额度：所有用公共额度的高德调用直接返回明确提示，自带 Key 的行程不受影响；
   - 暂停新建行程；
   - 一键停用所有邀请码；
   - 单个行程停用公共额度：最近用公共额度的行程列表，只显示 id、新建时间、邀请码、今天用量，不显示行程内容。
5. **应急手册**：写在管理页和 README 里。口令泄露时按顺序处理：
   1. 退出所有管理会话，暂停新建；
   2. 本机运行 `npx wrangler secret put ACCESS_CODE` 换口令；
   3. 检查邀请码和最近的行程，停用可疑的；
   4. 确认没问题后恢复。
6. **额度按类别细化**
   - 站长 Key 按高德的两类（路线测距类、搜索类）分别记「今天」和「本月」的用量。
   - 月预算可配置，`OWNER_MONTHLY_LBS_BUDGET` 默认 140000，`OWNER_MONTHLY_SEARCH_BUDGET` 默认 4500，都比高德的免费额度留一点余量。到预算就停下提示。
   - 管理页显示近 30 天每天的用量。
   - 高德没有查询剩余额度的接口，只能自己计数。条款或额度变了，改配置即可。
7. **公开额度状态** `GET /api/status`：只给粗粒度信息，节点缓存 60 秒。
   ```json
   { "public": { "level": "ok|tight|out|paused", "usedPct": 23, "searchMonthPct": 41 }, "creating": true }
   ```
   `tight` 指全站用量过了 80%；`out` 指用完了，或者搜索类月预算用完了。

验收：
- Worker 单元测试覆盖每一项，包括失败路径：口令错误、限次、会话过期和作废、开关生效与恢复、预算用完。
- 浏览器实测：设编辑口令后另一个人被请出，输入口令后恢复；管理页每个开关都能生效、能恢复。

## B. 前端质感与信息透明（首页、方案页、隐私页、编辑页外观）

1. **图标**：SVG 标志，配 favicon、apple-touch-icon、192/512 PNG。首页、编辑页、管理页、隐私页、方案页都用上，首页顶部有标志和名称。
2. **首屏效果图**
   - 用虚构的示例行程（不用真实成员和住址）生成：
     - 一张方案页截图（WebP，约 200KB 以内，带 PNG 兜底）；
     - 一个静态示例方案页 `/demo`。
   - 首页首屏展示截图，附「看示例方案页」链接。
3. **首页额度状态**：按 A.7 的接口展示「今天站点公共额度：已用 23%」，紧张时提示可以改用自己的 Key。接口不可用时整块隐藏。
4. **数据保留期放到明显位置**：
   - 首页新建按钮旁写明规则；
   - 编辑页顶部常驻「保留到 YYYY-MM-DD」，点开看说明；
   - 方案页页脚写「这一页会在 YYYY-MM-DD 前后自动删除」；
   - 隐私页把「保留多久、怎么删除」移到最前面，醒目显示。
5. **隐私与费用页修改**：
   - 「站长……除非排查故障不会去看」改成「只有排查故障的时候才有可能去看」；
   - Cloudflare 一行写明：免费套餐，和站长的其他服务共用一个账户的额度（每天 10 万次请求、KV 每天 1000 次写入等），用完当天报错、不会扣费；
   - 「自愿支持作者」的链接改为指向作者主页 <https://eigentime.org/>，不再出现支持、赞助字样。首页、编辑页、隐私页都改。
6. **打印**：方案页加「打印 / 存为 PDF」按钮和打印样式。打印时：
   - 隐藏按钮；
   - 地图固定高度；
   - 卡片不跨页；
   - 黑白打印也能看清。

验收：
- 手机和桌面宽度截图检查，没有横向溢出；
- 打印预览（`page.pdf`）的页面完整；
- 首页在接口不可用时不报错；
- 效果图和示例页里没有真实成员信息。

## C. 安全加固与收尾（A、B 合并之后）

- 所有响应加安全头：
  - `X-Content-Type-Options`、`Referrer-Policy`；
  - `frame-ancestors 'none'` 或 `X-Frame-Options`；
  - HTTPS 下加 HSTS；
  - 静态文件用 `_headers`。
- 首页、隐私页、管理页、编辑页加 CSP。编辑页要放行 Pyodide（jsDelivr、`wasm-unsafe-eval`）、Leaflet、marked、高德瓦片。cdnjs 上的脚本加 SRI 完整性校验。
- 所有改动状态的 `POST /api/*` 校验 Origin。
- 500 错误不把内部错误原文返回给客户端。
- 文档：README、隐私页（编辑口令、管理后台）、本计划的完成情况。
- 验收：完整浏览器 E2E（v3 的 20 项加本轮新增），控制台没有 CSP 报错；上线后线上再跑一遍。
