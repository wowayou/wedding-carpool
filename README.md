# 拼车出行规划（wedding-carpool）

一群人从不同城市去同一个地方（婚礼、聚会、团建……）：有人开车，有人坐高铁。这个工具用高德的真实行车时间先给出一个大方向，让大家心里有个底；具体在哪接、几点到，还是同行的人之间再商量。它回答：

- 不开车的人坐到哪个高铁站最合适（不一定是离目的地最近的那个）；
- 哪位车主顺路接谁、在哪接、几点出发，绕路不超过各自的上限；
- 搭不上车的人在哪个站汇合打车；
- 可选：散场后怎么回去（返程：车主顺路送人去车站或回家）。

结果包括：

- 推荐方案和备选方案；
- 每辆车的路线地图：灰色虚线是不接人时的直达路线，和实际路线对比，就能看出绕了哪段；
- 一页可以直接发给大家的**方案页**：每人一张时间线卡片，带高德导航链接；开了返程的话，另有返程一节。

线上版：<https://carpool.eigentime.org> ，首页有效果图、示例方案页（`/demo`）、适合哪些场合和常见问题，不用注册。也可以在本机运行，或者自己部署一份。

## 使用流程

1. **目的地**：搜索并选中，坐标最准。
2. **成员**：谁开车、空几个座、最多愿意绕多久；每个人的出发地。几个人一起走（比如带家属）的，填「同行人数」，这组人会一起上同一辆车，或者一起打车，不会被拆开。选好或算过的地点会马上显示在地图上，坐标存进配置，下次不再查。
3. **候选车站**：点「推荐车站」，会在三个范围里找火车站：
   - 目的地周边约 100 公里；
   - 各车主出发地附近；
   - 沿各车主的路线每隔 30 公里。

   不在 12306 站名表里的站（多半是货运站）会被去掉。结果按「车主顺路去接最少多绕多久」排序，勾选加入即可。
4. **车次**：不开车的人在每个站后面点「查」，打开已填好出发城市、到达站和日期的 12306 页面，查到后填入车次和时刻（如 `G1234 08:00→11:30`）。程序会自动算用时，并倒推车主几点出发。
5. **返程（可选）**：打开「返程」，填散场时间。不开车的人填回程车次（同样有 12306 查询链接），程序按「发车前多久到站」（默认 40 分钟）倒推；车主可以选返程是否顺路送人、最多绕多久。
6. **计算方案**：先让尽量多的人搭上顺风车，每位车主的绕路不超过上限；再比总分钟数（车主绕路 + 乘客坐车 + 打车组车程）。去程和返程分别出方案，可以分别选。
7. **发布方案页**：每个行程一个方案页链接，重新发布会更新同一个链接。

## 在线版

- **新建行程**：首页填行程名称，然后二选一：
  - 有**邀请码**（站长发的，也可以直接打开邀请链接 `/?invite=<邀请码>`），用站点的公共高德额度；
  - 填**自己的高德 Web 服务 Key**。Key 只保存在服务端，不会回传到网页，调用次数算在你自己的额度里。
- **编辑链接即权限**：形如 `/t/<行程>#k=<密钥>`，发给一起规划的人就能多人同时编辑。链接外传了，可以在「更多」里**重置**，旧链接和已经打开的页面立即失效。
- **编辑口令（可选，默认关）**：在「更多」里设置。设了以后，新设备打开编辑链接要先输入口令，已经在线的其他人会被请出、要重新输入；每个行程每小时最多试 10 次。清除后只凭编辑链接就能打开。
- **方案页**：链接形如 `/p/<方案页 id>`，和行程 id 无关，只能看不能改。v3 之前发布过的行程沿用原来的 `/p/<行程 id>`，重新发布还是更新这个链接；想分开可以在「更多」里换链接。
  - 车主的路线从出发地约 2 公里外开始画，「到家附近接」的地点不标位置，导航链接不带出发地。
  - 可以设**访问口令**（每个方案页每小时最多试 20 次）、**换一个链接**（旧链接失效）或**停止分享**。
  - 页面上有「打印 / 存为 PDF」按钮，打印时隐藏按钮、地图固定高度、卡片不跨页，黑白打印也能看清。
- **多人实时编辑**：
  - 改动停顿约 0.8 秒后自动保存；
  - 顶部显示谁在线，正在被别人编辑的格子会标出名字；
  - 两人改了不同的地方会自动合并；改了同一格时，保留后保存的一方，并给他弹出提示「对方改成了什么」，可以一键改用对方的；
  - 断线期间的改动，恢复后补存。
- **历史版本**：同一个人 2 分钟内的连续修改合并成一条，每个行程保留最近 100 条。可以查看和现在的差别、一键恢复；恢复本身也会生成新版本，还能再撤回。
- **调用上限**：
  - 用公共额度的行程：每个行程每天最多 1500 次（邀请码可以单独设），全站每天最多 4000 次高德调用。全站用过八成后，当天还没用过公共额度的行程暂停分配，留给已经在算的行程。
  - 自带 Key 的行程每天最多 3000 次，只防程序出错时无限调用。
  - 站点公共额度按高德的两个类别（路线测距类、搜索类）分别记今天和本月的用量，到月预算就停下提示。月预算默认路线测距类 140000 次、搜索类 4500 次，比高德的免费额度留了余量，可以用可选变量 `OWNER_MONTHLY_LBS_BUDGET`、`OWNER_MONTHLY_SEARCH_BUDGET` 调整。高德没有查询剩余额度的接口，只能自己计数；条款或额度变了，改配置即可。
  - 高德返回配额用完时，按 Key 和接口类别（搜索类、路线测距类）分开记住，北京时间次日零点前这一类不再调用。高德个人开发者的搜索配额比路线类少得多，搜索用完了不影响算行车时间。
  - 到上限都是停下提示，不会继续调用；提示里可以直接改用自己的 Key。
- **数据保留期**：出行日期过后 60 天、连续 180 天没人编辑，两者取较晚的，到期自动删除行程和方案页；删除前 7 天编辑页会提示。「更多」里可以随时手动删除。
- **其他**：
  - 配置可以导出、导入（JSON）；
  - 公开额度状态：`GET /api/status` 只返回粗粒度信息（`ok`、`tight`、`out`、`paused` 四档、已用百分比、能否新建），节点缓存 60 秒；首页据此显示「今天站点公共额度：已用 23%」，紧张时提示可以改用自己的 Key，接口不可用时整块隐藏；
  - 同一 IP 每天最多新建 10 个行程，全站每天最多 200 个；
  - 存了什么、给了哪些第三方、哪里可能花钱，见站内的[费用与隐私](https://carpool.eigentime.org/privacy)页。

### 管理页

站长在 `/admin` 用站长口令登录。站长口令**只用于管理页**，不能在首页当邀请码用；登录后发的是随机会话令牌（24 小时过期），不是口令本身。可以：

- 看今天和本月的公共额度用量（按两个类别分开）、近 30 天每天的用量、今天新建的行程数；
- **用公共额度新建行程**：直接给出编辑链接，不需要邀请码；
- 发邀请码：备注、最多建几个行程、有效期、每个行程每天的高德上限；
- 看每个邀请码建了几个行程、今天用了多少；停用或重新启用。邀请码停用后，用它建的行程不能再用公共额度，要改用自己的 Key，已有数据不受影响；
- **应急开关**（置顶，操作要二次确认，最近 50 条操作有记录）：暂停公共额度（用公共额度的行程立刻停止计算并提示改用自己的 Key，自带 Key 的不受影响）、暂停新建行程、一键停用所有邀请码、退出所有管理会话、对单个行程停用公共额度。「最近用公共额度的行程」只显示行程 id、新建时间、所用邀请码和今天用量，不显示行程内容。

### 应急处理

站长口令可能泄露了，按顺序处理（管理页里也有同样的手册）：

1. 在管理页点「退出所有管理会话」，再暂停新建行程，需要的话也暂停公共额度；
2. 在本机运行 `npx wrangler secret put ACCESS_CODE` 换口令，旧口令立刻失效；
3. 检查邀请码和最近用过公共额度的行程，可疑的邀请码停用、可疑的行程停用公共额度，也看一下「最近操作」里有没有不是你做的；
4. 确认没问题后，把暂停的开关恢复。

登录失败有次数限制（同一网络 15 分钟 5 次、全站每小时 30 次）。

## 本地版

需要 Python 3.11+，只用标准库。高德 Key 放在环境变量 `AMAP_KEY` 里，或者存进同目录的 `.amap_key`（已加入 `.gitignore`）。

```bash
python3 ui.py            # 编辑 trip.toml，打开 http://127.0.0.1:8765
python3 carpool.py trip.toml   # 只用命令行：报告打印到终端，并写到 trip-report.md
```

返程在 TOML 里加一节 `[return]`（`enabled`、`depart_time`、`security_min`、`date`），成员的回程车次写在 `return_trains`，同行人数写 `party`，见 `trip.example.toml`。

本地版是单人使用：没有多人同步和历史版本，需要手动保存。保存时会把配置写回 TOML，手写注释不会保留；第一次保存前，原文件会备份为 `trip.toml.bak`。字段说明见 `trip.example.toml`。

## 自己部署（Cloudflare Workers）

```
浏览器：界面 + Pyodide（浏览器里运行的 Python，跑 carpool.py 等，计算都在这里）
   │  编辑链接换来的 Cookie（只对该行程的路径有效）；WebSocket 实时同步
   ▼
Worker（web/worker.js，用 placement.region 固定在香港附近运行，离高德近）
   ├─ 新建行程：校验邀请码或自带 Key，限制新建频率
   ├─ ConfigRoom（Durable Object，每个行程一个）：配置、版本号、历史、当天用量、在线名单、
   │                                         方案页设置、到期删除的定时任务
   ├─ Usage（Durable Object）：全站新建次数、站长 Key 当天用量、邀请码
   ├─ 高德代理：只放行用到的接口；先查 Cloudflare 节点缓存，再按每秒 3 个批量请求
   ├─ 管理页接口：/api/admin/*，站长口令登录，之后凭会话令牌
   └─ KV：方案页（带访问口令和过期时间）、按 Key 和接口类别记的配额标记
```

计算内核（`carpool.py`）以「一段行程」（leg）为单位求解：去程是车主从家出发接人去目的地，返程是从目的地出发送人。座位按同行人数算，一组人不拆开。方案页由 `share.py` 生成，编辑器是 `ui.html`（本地版和在线版共用）。

需要 Node.js、Cloudflare 账号，以及一个高德 Web 服务 Key。免费套餐就够用，超出免费额度只会报错，不会扣费。

```bash
npm install
npx wrangler login
npx wrangler kv namespace create DATA      # 把输出的 id 填进 wrangler.jsonc
npx wrangler secret put AMAP_KEY           # 站长的高德 Web 服务 Key
npx wrangler secret put ACCESS_CODE        # 站长口令：只用来登录管理页 /admin
npm run deploy                             # 构建 dist/ 并部署
```

可选设置：

- 在 `wrangler.jsonc` 的 `vars` 里设 `TRIP_DAILY_LIMIT`、`OWN_TRIP_DAILY_LIMIT`、`OWNER_DAILY_LIMIT`，调整每日上限；设 `OWNER_MONTHLY_LBS_BUDGET`、`OWNER_MONTHLY_SEARCH_BUDGET`，调整站点公共额度的月预算（默认 140000 和 4500）；
- 在 `routes` 里绑定自己的域名。`workers.dev` 域名在国内不翻墙常常打不开。
- 不设 `AMAP_KEY` 和 `ACCESS_CODE` 的话，就只能自带 Key 新建行程。
- 高德 Key 的使用条款和配额以[高德开放平台](https://lbs.amap.com/)为准。按 2025 年 5 月起的定价，个人认证开发者「非商业目的」的免费月配额是：路线、测距、地理编码等基础服务 15 万次，关键字、周边等搜索服务 5000 次，只有认证后的第一年；用于商业目的要另外购买许可。部署前请自己确认你的用途符合条款。

本地调试：在 `.dev.vars` 里写上 `AMAP_KEY=...` 和 `ACCESS_CODE=...`，然后运行 `npm run dev`。12306 站名表 `web/stations12306.json` 由 `web/gen_stations12306.py` 生成，需要时重新生成。

## 搜索引擎与 AI 问答

首页带 Open Graph、Twitter 卡片和 JSON-LD（`WebApplication` 与 `FAQPage`）。`robots.txt` 允许首页、`/demo`、`/privacy`，禁止 `/t/`、`/p/`、`/api/`、`/admin`；另有 `sitemap.xml` 和 `llms.txt`（给 AI 问答读的简短说明）。`/demo` 是静态的示例方案页，行程是虚构的。编辑页和管理页带 `noindex`。这几个文件都在 `web/` 下，换了域名要一起改。

## 安全措施

- 构建时（`web/build.mjs`）给每个页面生成内容安全策略（CSP）：内嵌脚本按哈希放行，不允许 `unsafe-inline` 和 `unsafe-eval`；cdnjs 上的脚本和样式带 SRI 完整性校验。
- 所有响应都带安全头（`nosniff`、`X-Frame-Options`、`Referrer-Policy`、HSTS、`Permissions-Policy`）：静态文件在 `web/_headers`，Worker 生成的响应在 `web/worker.js`，两处要保持一致。
- 方案页的 HTML 由编辑者的浏览器上传，所以放进 CSP 沙箱（独立的匿名来源）：读不到本站的存储和 Cookie，也不能发请求。
- 改动状态的请求（`/api/*` 的 POST 和 DELETE、方案页口令表单）校验 Origin，跨站来源会被拒；WebSocket 也校验 Origin；500 错误不返回内部错误原文。
- Cloudflare 的 Web Analytics 会自动往页面里注入统计脚本，和「不做统计埋点」不一致，而且会被 CSP 拦下。自己部署时请在 Cloudflare 后台关掉。

## 已知限制

- 行车时间来自高德驾车测距，接近查询时的路况，每次查会浮动几分钟，当天也可能有出入。
- 不调用 12306 的非公开接口，车次需要手填。不填车次时，会用高德公共交通估算，但高德跨城只给直达火车、不含换乘，也查不到刚开通的线路，可能很不准。
- 推荐车站分不出高铁站和普速站，选的时候留意一下。
- 同一格两人同时改时，保留后保存的一方；先保存的一方的改动，可以在提示里一键改回，或者去「历史」里找回。
- 方案页存在 KV 里，重新发布后，其他地区可能要等约一分钟才看到新内容。
- 方案页模糊了车主出发地，但路线和车站仍然能看出大致区域，只发给相关的人；需要的话加访问口令。
- 返程只考虑车主从目的地送人去车站或顺路的家，不考虑在车站之间换乘；打车费用是按里程的粗估。
