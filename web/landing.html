我打开过的行程

新建行程

在 高德开放平台控制台（个人需实名）→ 应用管理 → 创建应用 → 添加 Key，服务平台选「Web服务」，不要设 IP 白名单。Key 只保存在服务器上，不会再显示在网页里；调用次数算在你自己的免费额度里，用完会停下提示。

行程会在「出行日期过后 60 天」和「连续 180 天没人编辑」中较晚的那天自动删除，也可以随时手动删。

新建后会得到一个编辑链接，发给一起规划的人就能多人同时编辑。只想让大家看结果的话，发之后生成的方案页链接就行。

适合哪些场合

  • 婚礼：亲友从各地来，安排谁开车顺路接谁、不开车的人坐到哪个站。
  • 同学或家庭聚会：几家人从不同城市出发，算出哪辆车顺路带上谁，少开几辆车。
  • 团建和公司活动：同事分散在几个城市，先定好在哪个站汇合、几点出发。
  • 自驾游拼车：几辆车各自出发，沿途顺路接上坐高铁来的朋友。
  • 去看演唱会和比赛：外地的朋友约着去同一座城市，拼车或在车站汇合。
  • 会议和活动的接站：外地嘉宾坐高铁到站，安排车主顺路接到会场。

常见问题

怎么决定在哪个高铁站接人？

先在目的地周边、车主出发地附近和沿途自动找候选高铁站，再按车主顺路的程度、不开车的人坐车到站的时间排序；填了车次的话，会按到站时间倒推车主几点出发。最后选哪个站，大家看完方案再商量。

要注册吗？要钱吗？

不用注册，没有账号，也没有广告和付费功能。新建行程需要站长发的邀请码，或者填你自己的高德 Key；拿到编辑链接的人就能一起编辑。

数据存多久？谁能看到？

行程在「出行日期过后 60 天」和「连续 180 天没人编辑」中较晚的那天自动删除，也可以随时手动删除。行程只有拿到编辑链接的人能看到和修改；方案页拿到链接就能看，不含精确的出发地和家庭位置。

算出来的结果准吗？

它只是帮你先定个大方向、心里有个底：行车时间和路线来自高德地图，按查询时的路况估算，只供参考。具体在哪接、几点到，同行的人在群里再商量；当天以实际路况为准，车次和余票以 12306 为准。

能不能自己部署一份？

可以。代码开源（AGPL-3.0），按 GitHub 仓库的说明用自己的 Cloudflare 账号和高德 Key 部署即可，数据完全在你自己手里。

数据保存在 Cloudflare：行程只有拿到编辑链接的人能看到和修改；方案页链接拿到就能看，可以加访问口令，不含精确的出发地和家庭位置；行程按期限自动删除。详见费用与隐私。 开源：github.com/wowayou/wedding-carpool，可以自己部署一份。
